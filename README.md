# Simple Interest Calculator

A simple and responsive interest calculator built with **HTML, CSS, and JavaScript**.

![Simple Interest Calculator](images/calculator.png)

## 📌 About

This project is a simple interest calculator that calculates the final amount based on:

* Principal amount
* Interest rate
* Number of years

The calculator uses the simple interest formula:

**Simple Interest = (Principal × Rate × Time) / 100**

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ✨ Features

* Enter the principal amount
* Select the interest rate using a range slider
* Enter the number of years
* Calculate the interest and final amount
* Responsive and modern user interface
